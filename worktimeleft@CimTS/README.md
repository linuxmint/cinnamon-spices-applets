# Work Time Left

A Cinnamon panel applet that shows how much time is left in your workday.

## Features
- Configurable start and end times (24h `HH:MM`)
- Overnight shifts: set an end time earlier than the start time (e.g. 22:00 to 06:00)
- Choose your workdays
- Shows a countdown before your shift starts, and "Workday over" after it ends
- Optional percent-of-day display; the tooltip shows time worked
- Updates on the minute

## Configuration
Right-click the applet and choose **Configure...**.
