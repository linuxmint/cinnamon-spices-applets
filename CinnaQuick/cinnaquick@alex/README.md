# CinnaQuick

CinnaQuick is a modern quick settings applet for the Cinnamon desktop.

## Features

- Wi-Fi toggle
- Network settings
- Bluetooth toggle
- Volume slider
- Brightness slider
- Clock and date
- Notification settings
- System update manager

## Requirements

CinnaQuick uses standard Cinnamon, NetworkManager, PulseAudio/PipeWire PulseAudio compatibility, and xrandr tools available on the system.
