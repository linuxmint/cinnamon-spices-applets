# Taskbar Menu

Taskbar Menu is a Cinnamon applet that lets you create custom application menus directly in the Cinnamon panel.

Each instance of the applet can have its own name, icon and selection of applications. Multiple instances can be added to the panel to create separate menus for different purposes.

## Features

* Create custom application menus in the Cinnamon panel
* Add multiple independent menu instances
* Choose which applications appear in each menu
* Browse applications using the standard Cinnamon application categories
* Search for installed applications
* Select and remove multiple applications
* Launch applications directly from the custom menu
* Choose between icon only, text only, or icon and text
* Choose a custom menu name
* Choose a custom menu icon
* Move the application management dialog around the screen

## Usage

1. Add Taskbar Menu to the Cinnamon panel.
2. Open the applet settings.
3. Choose a name, icon and panel display mode.
4. Open the Applications page.
5. Click "Manage applications…".
6. Select the applications you want to include.
7. Click "Apply".
8. Click the applet in the panel to open your custom application menu.

To create another independent menu, simply add another instance of Taskbar Menu to the panel.

## Compatibility

Taskbar Menu is currently tested with Cinnamon 6.6.
