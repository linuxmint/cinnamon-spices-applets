# Media Clock

Cinnamon applet: reloj con Dynamic Island estilo iPhone.

Muestra la cancion actual con portada, controles y barras de
progreso y volumen al hacer clic sobre el reloj del panel.

**Ubicacion del applet:** `media-clock@Juanes767/files/media-clock@Juanes767/`

Este repositorio es un fork de [linuxmint/cinnamon-spices-applets](https://github.com/linuxmint/cinnamon-spices-applets)
para contribuir el applet Media Clock.
