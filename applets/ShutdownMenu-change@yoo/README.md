# Shutdown Menu - change

一个小巧实用的 Cinnamon 面板小程序。

## 📖 简介

这个小程序会在 Cinnamon 面板上添加一个图标，点击后可以快速访问以下系统功能：

- **关机**：弹出系统确认对话框
- **注销**：弹出系统确认对话框
- **锁屏**：立即锁定屏幕（**无确认提示**）

---

## ⚙️ 设置

### 面板图标

- 可自由选择图标（支持系统图标或自定义图片路径）
- 可调整图标大小（16–64 像素）

### 菜单选项

- 勾选对应的复选框以添加项目，取消勾选以删除项目
- 通过替换图标名称或浏览至图标文件来更改图标
- 通过替换命令来更改命令（支持自定义命令）

> 💡 **所有更改都会立即生效**，无需重启 Cinnamon。
