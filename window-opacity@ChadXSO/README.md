# Window Opacity

Make your windows see-through, with a default opacity for every app and a remembered setting per app.

- Every app opens at a default opacity (75% out of the box), including windows you open later.
- Each app remembers its own setting. Set Nemo to 85% once and every Nemo window opens at 85%, even after a reboot.
- Click the panel icon for two sliders: one for the app you last used, one for the default.
- Scroll on the icon to change the current app in 5% steps.
- Fullscreen games and videos stay solid.
- Never goes below 20%, so nothing disappears.

## Use it

1. Click a window so it's the active one.
2. Click the applet icon.
3. Drag the top slider for that app, or the bottom slider for the default.

"Make this app solid" keeps an app at 100%. "Put this app back on the default" forgets the app's own setting. The default can also be changed from the applet's Configure dialog.

Removing the applet from the panel puts every window back to solid.
