# Workspace Switcher Plus (Cinnamon Applet)

Workspace Switcher Plus is a Cinnamon panel applet that lets you switch workspaces directly from the panel, with extra appearance controls and interaction options.

This project is based on the original Workspace Switcher applet from the Cinnamon team and extends it with additional customization.

## Features

- Switch workspaces from the panel with a single click.
- Optional visual workspace representation mode.
- Configurable scroll wheel behavior (normal, reversed, or disabled).
- Custom colors for active and inactive workspace buttons and text.
- Adjustable inactive button opacity.
- Adjustable workspace button border radius and border color.

## Manual Installation

Install manually from this repository into your local Cinnamon applets directory as follows:

```bash
cp -r files/workspace-switcher-plus@tiagomiguelcs ~/.local/share/cinnamon/applets/
```

Then restart Cinnamon:

- Press `Alt` + `F2`
- Type `r`
- Press `Enter`

After restarting, add the applet from the Cinnamon Applet Settings.
