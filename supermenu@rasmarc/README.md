# SuperMenu

SuperMenu puts an applications menu and an editable custom menu on the Cinnamon
panel. The applications menu has drawer and classic layouts. The custom menu
can show drawers, a list or a grid, and can be hidden independently.

Right-click the applet to configure it. In the custom menu, right-click an
entry, a category or **No entries yet** for editing and the shortcuts to copy
from the applications menu or load a template. When the custom menu already
has content, choose a file and click **Replace** to load the template. You can
back up and load your own menu in the settings. Turn off **Extended context
menu** under **Behavior → Custom menu** to hide the shortcuts in normal use.

**Ctrl+Super** opens the applications menu and **Alt+Super** starts or ends
editing. **Super** opens the custom menu by default when Cinnamon's standard
menu does not use that key. You can change the shortcuts in the settings.

Requires Cinnamon 6.6. Tested on Cinnamon 6.6.9 with X11. The applet is based
on Cinnamon's standard applications menu. See the packaged `NOTICE.md` and
`COPYING` for credits and license terms.
