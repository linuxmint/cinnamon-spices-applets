# Desktop Drawer changes

## 1.2.0 (2026-09-22)

- Show the current folder name and a Choose folder action in the drawer.
- Use plain wording throughout the menu and settings.
- Replace the panel artwork with a simple drawer icon that reads at small sizes.
- Respect the hover setting for submenus as well as the panel icon.
- Keep leading and trailing spaces in selected folder paths.
- Cancel pending directory reads when the drawer closes.
- Show a notification when the default application cannot open an item.
- Add current dark, light, empty, unavailable and settings screenshots.
- Add repeatable desktop tests, screenshot provenance, beta instructions and reproducible archives.

## 1.1.0 (2026-09-22)

- Prepare the standalone Cinnamon Spices package under GPL-3.0-or-later.
- Add native folder and hover settings.
- Load directories asynchronously and submenus on demand.
- Keep Private folder contents hidden at every browsing depth.
- Include an installation ZIP, translation template and submission checklist.

Neither candidate has been submitted to Cinnamon Spices yet.
