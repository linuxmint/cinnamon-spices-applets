# Internet Speed Monitor

A compact, ergonomic network speed applet for the Cinnamon panel that shows the
**real download and upload speed of the connections that actually reach the Internet**,
with small live graphs.

## Features

- **Automatic interface detection**: by default only the interfaces holding a default
  route (IPv4 or IPv6) are counted, i.e. Wi-Fi, USB tethering (Android and iPhone),
  Ethernet or mobile broadband. Docker, virtual bridges, `veth` and loopback are ignored.
  If two connections are active at the same time their speeds are added up.
- **No double counting with VPNs**: when a physical interface carries the default route,
  the VPN tunnel is not added on top of it.
- **Real speed**: bytes are divided by the actual elapsed time measured with a monotonic
  clock, not by the nominal update interval.
- **Mini graphs in the panel**: two separate graphs (download / upload) or one combined
  graph, with a logarithmic scale (default) so both light and heavy traffic are visible,
  or a linear auto-scaling one.
- **Fixed-width text** on two lines: the applet never changes width while the numbers
  change, so the other panel icons do not jump around.
- **Tooltip** with per-interface speeds.
- **Popup menu** with a larger graph (last ~160 samples), peak values (resettable) and,
  for each interface: type, name, IPv4 address, current speed and total traffic since
  the connection came up. Shortcuts to Network settings and System Monitor.
- Works on horizontal and vertical panels.

## Settings

- Update interval (0.5–10 s)
- Unit: bytes (kB/s, MB/s) or bits (kb/s, Mb/s)
- Monitored interfaces: automatic, all active physical interfaces, or a manual list
- Show/hide graphs, graph type, width and scale
- Show/hide text, one or two lines
- Download and upload colors, optional colored text

## How it works

Counters are read from `/proc/net/dev`; the Internet-facing interfaces are found in
`/proc/net/route` and `/proc/net/ipv6_route`; the interface type is detected from
`/sys/class/net`. No external programs are run periodically (only `ip` once, when the
menu is opened, to show the IP addresses).
