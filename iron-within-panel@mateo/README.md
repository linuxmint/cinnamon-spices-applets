# Cinematic Grade

Cinematic Grade is a color grade for the whole Cinnamon desktop. Click the panel icon to turn it on. Click again to turn it off. The default shortcut is Super+G. The grade starts off.

The filter does not change the monitor ICC profile, gamma ramps, or colord.

## Install on Linux Mint

Cinnamon 6.0 or newer. That is Mint 21.3, and Mint 22 through 22.3.

1. Open the menu and go to System Settings, then Applets.
2. Open the Download tab.
3. Search for Cinematic Grade and install it.
4. Open the Manage tab and add Cinematic Grade to the panel.

## Use

Click the hooded icon. While the grade is on, the icon takes a teal grade. Right-click the icon and choose Configure.

- Preset: Subtle, Cinematic, Iron Within, Extreme.
- Intensity: 0 keeps the original image. 1 applies the full preset.
- Shortcut: Super+G by default. An empty shortcut leaves the click.
- Keep fullscreen windows composited: while the grade is on, fullscreen windows stay in the compositor so the shader can see them. Turning the grade off restores the previous setting.

You need a GPU with GLSL. No extra package is required.
