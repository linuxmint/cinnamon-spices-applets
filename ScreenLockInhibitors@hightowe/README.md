# Screen Lock Inhibitors

A Cinnamon panel applet that monitors `org.gnome.SessionManager` over D-Bus to indicate whether screen blanking, locking, or idle deactivation is currently inhibited.

## Features
* Compact icon indicator (green when screensaver is allowed, red when inhibited).
* Tooltip summary of blocking applications.
* Clickable popup menu detailing active inhibitors and their reported reasons.
