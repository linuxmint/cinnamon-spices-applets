# Disk Space (Cinnamon Applet)

A simple Cinnamon panel applet that displays remaining disk space. You can add multiple applet instances to monitor different filesystems or paths.

## Manual Installation

Install manually from this repository into your local Cinnamon applets directory as follows:

```bash
cp -r files/disk-space@tiagomiguelcs ~/.local/share/cinnamon/applets/
```

Then restart Cinnamon:

- Press `Alt` + `F2`
- Type `r`
- Press `Enter`

After restarting, add the applet from the Cinnamon Applet Settings.
