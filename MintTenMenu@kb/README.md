
MintTenMenu
===========

<img width="256" height="256" alt="icon" src="https://github.com/user-attachments/assets/64d0f384-1ebc-4dc6-9517-0488d0f7259f" />

A Windows 10-style Start Menu for Cinnamon, with a navigation rail, searchable
app list, and a resizable tile area.

### Features

 * Start menu with a Windows 10-inspired layout.
 * Navigation rail with user avatar, Places shortcuts, and power options.
 * Searchable, categorised application list.
 * Customisable tile grid with drag-and-drop placement, resizing, folders, and
  multiple tile groups.
 * Right-click an app to open it, add it to the panel or desktop, uninstall it,
  view its properties, or pin it to Start.
 * Tiles are removed automatically when the underlying application is
  uninstalled.
 * Optional desktop widgets: weather, finance/forex, quote, calendar, todo,
  tasks, and screen time.
 * Configurable Start button icon (Default, Black, White, or a custom icon) and
  optional panel label.

### Installation

Install **MintTenMenu** from *System Settings → Applets*, or download the ZIP
from the Cinnamon Spices website and use *Install applets from file*.

After installing, add it to a panel and click the Start button.

### Configuration

Right-click the applet and choose *Configure* to set the Start button icon,
label, behaviour, and tile layout options. Widget settings are available from
the gear button on each widget tile.

### Notes

Tile layouts, widget configuration, and local todo data are stored in
`~/.config/wintenmenu/`.
